# Hi👋

Full-Stack Software Engineer working with TypeScript, Node.js and C#/.NET.
I love turning ideas into digital products that create real value.

## 🎯 Focus Areas

- 🧩 **Full-Stack Development**: On the frontend, I focus on modern Angular with a clean, modular
  architecture, server-side rendering where it makes sense, and responsive, accessible UIs.
  On the backend, I design and build REST APIs with Node.js/NestJS and C#/.NET.
- ☁️ **Cloud-Architecture**: Building and integrating services into cloud-based microservice
  architectures on Azure (Container Apps, Key Vault, PostgreSQL, Managed Redis),
  containerized with Docker and Docker Compose.
- 🔭 **Observability & Operations**: Using OpenTelemetry and Application Insights to observe
  running systems, trace failures across service boundaries and get to the root cause quickly.
- 🔐 **Secure Software Development**: Security by design. Role-based access control with access tokens, and security-relevant
  architecture decisions in line with compliance requirements.
- ✅ **Quality & Documentation**: Unit and integration tests for every new feature, growing E2E coverage,
  and clear documentation through architecture decision records.
- 🤖 **Agentic Software Engineering**: Using AI agents like GitHub Copilot, Codex and Claude Code
  to speed up and improve software development in a structured, reliable way.
